# Support

Read the [README](README.md) first for installation, invocation, requirements, and limitations.

Use [GitHub Issues](https://github.com/montasim/skills/issues) for reproducible bugs, documentation problems, and focused feature requests. Include the package version, agent host, operating system, command or prompt used, expected result, actual result, and relevant sanitized output.

For vulnerabilities, follow the [Security Policy](SECURITY.md) instead of opening a public issue. Optional [SupportKori funding](https://www.supportkori.com/montasim) is not a technical-support channel.
