# Support

The central GitHub repository has not been created yet. Until the remote cutover is complete, use the issue tracker linked from the affected published skill's README. Source-only skills do not yet have a public issue tracker. Skillfolio application issues remain at the standalone [Skillfoliox issue tracker](https://github.com/montasim/Skillfoliox/issues) until its public source and deployment move to the central repository.

Include the skill name, host, installation scope, runtime version, expected behavior, sanitized actual output, and a minimal reproduction. Never include credentials, private repository content, personal data, or secret values.

The [SupportKori page](https://www.supportkori.com/montasim) is a funding channel, not a technical-support channel.
