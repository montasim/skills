# Support

Use the central [skills issue tracker](https://github.com/montasim/skills/issues) for reproducible installer, package, and Agent Skill defects. Skillfolio application issues remain at the standalone [Skillfoliox issue tracker](https://github.com/montasim/Skillfoliox/issues) until the deployed application's source and issue history move to the central repository.

Include the skill name, host, installation scope, runtime version, expected behavior, sanitized actual output, and a minimal reproduction. Never include credentials, private repository content, personal data, or secret values.

The [SupportKori page](https://www.supportkori.com/montasim) is a funding channel, not a technical-support channel.
