# Skillfolio prototype — v1

A static, responsive prototype for browsing Montasim's personal AI agent skills.

Open `index.html` in a browser. The prototype uses the Tailwind CSS CDN and Google Fonts, so an internet connection is required for the full visual treatment.

## Included flows

- Browse and filter the skill library
- Search by skill name, category, or description
- Copy skill commands
- Open deep-linked skill detail pages via `skill.html?skill=...`
- Switch between overview, workflow, and usage tabs
