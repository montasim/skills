# Licensing

Licensing is defined per skill rather than by one repository-wide license.

The following skill directories contain their own MIT License:

- `find-ui-inconsistencies`
- `publish-verified-github-release`
- `deploy-prebuilt-app-to-netlify`
- `fix-social-link-previews`
- `make-project-github-ready`
- `make-app-netlify-ready`
- `update-skillfolio-catalog`
- `release-agent-skill`
- `fix-project-metadata-mismatches`
- `verify-github-npm-release`
- `write-complete-project-readme`

The following directories do not currently include an open-source license:

- `integrate-supportkori-widget`
- `apps/skillfolio`

No open-source permission should be inferred for unlicensed skill directories, the Skillfolio application, or root-level aggregation and release tooling. Importing previously public source into this monorepo does not create a license grant. A future repository-wide license decision must explicitly account for these exceptions before adding a root `LICENSE` file.

`integrate-supportkori-widget` is distributed publicly on npm with the manifest value `UNLICENSED`. Registry and source visibility do not create permission to copy, modify, or redistribute that skill.
